### 4. Known Edge Cases & Troubleshooting
1. **Asset Not Found**: If an unknown or decommissioned ID is passed in the URL (e.g. `/asset-passport?id=AST-UNKNOWN`), the screen gracefully displays an "Asset Not Found" card with a "Return to Home" button.
2. **Cold Start / Offline**: If database query is pending or server is waking up, the route falls back seamlessly to local mock seeder data so scanning never breaks.
